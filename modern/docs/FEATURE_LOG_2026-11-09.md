# 2026-11-09 · 학생 계정 및 학습 분석 고도화 기록

## 목적
기존 교사 전용 파일 CMS를 **학습 운영 플랫폼**으로 발전시키되 원본 강의 HTML/CSS/JS와 디자인 시스템을 건드리지 않습니다. 추가 기능은 모두 Cloudflare Workers Free + 이미 운영 중인 D1 기반입니다.

## 변경 내용
1. Google Access subject 기준 학생별 고유 UUID(`FL-...`) 발급·유지.
2. 학생 마이페이지 /me: 계정 식별자, 본인 점수·평균·최고점·문제별 기록·학습 그래프.
3. 선생님 /admin: 기존 Google + 비밀번호 2단계 인증 뒤 미니멀한 그래픽 대시보드, 학생별 기록 검색·조회.
4. 문제 관리: 별도 Quiz Studio를 만들어 객관식·단답형 문제/보기/정답/해설 추가·수정, 초안·게시·버전 관리.
5. 기존 공통 퀴즈엔진: **원본은 그대로 보존**하고 빌드된 복사본에 기록 제출 기능만 연결. 클라이언트가 점수를 지정할 수 없고 서버가 답안으로 재채점.
6. 원본 강의 퀴즈에서 새 문제를 가져오고 새 관리형 문제로 복사하는 기능. 원본 JS 자체 수정은 종전 CMS에서 가능.
7. 신규 D1 마이그레이션 `0003_learning_profiles_quizzes.sql`: 4개 테이블/인덱스.
8. API 및 테스트·운영 문서 확장.

## 실제 작업
- Cloudflare D1 `frontend-lab-cms`에 새 테이블/인덱스를 실제 생성했습니다(10개 DDL 단계 성공).
- 이미 등록되어 있던 학생 계정 1개에 고유 ID를 부여했습니다. 신원·이메일·ID 원문은 공개 문서에 기록하지 않았습니다.
- D1에서 **합성 학생·퀴즈·게시 버전·응시 결과 저장**의 INSERT/SELECT/DELETE를 모두 검증했습니다. 합성 데이터는 정리했습니다.
- 프론트엔드 및 Worker 코드는 별도 기능 브랜치에서 개발해 기존 main 서비스를 즉시 변경하지 않는 방식으로 진행했습니다.
- 최종 Cloudflare Build의 단위 테스트/TypeScript/Vite 검증 및 브라우저 인증 테스트 완료 전에는 실제 운영 완료라고 주장하지 않습니다.

## 학습 평가에 대한 경계
기존 퀴즈는 정답이 포함된 JavaScript로 배포되므로 결과가 **공식 시험 성적을 증명하는 것은 아닙니다**. 새 관리형 퀴즈는 서버 채점·정답 비노출 구조이지만, 브라우저 기반 학습 플랫폼이므로 여전히 고부담 평가 부정행위 방지를 보장하지 않습니다.

## 변경 없는 것
- 선생님 원본 교육 자료 파일
- 기존 Google 로그인 정책, 선생님 전용 비밀번호 인증
- GitHub Actions 비사용
- 무료 Workers/D1 및 `frontend-lab.rhee.life` 도메인
- 다른 프로젝트의 Cloudflare 자원
