## 창조자만 할 수 있는 작업

Blue Renaissance CMS /admin의 **권한 관리** 탭에서:

1. 학생 이름/Google 이메일/고유 학습 ID로 가입한 계정을 검색합니다.
2. **관리자 임명**을 누르면 해당 계정을 2순위 CMS 관리자로 승격합니다.
3. 나중에 **권한 박탈**을 누르면 CMS 접근권이 즉시 철회됩니다.
4. 모든 작업은 D1 `lab_admin_audit`에 수행자, 대상, 시각, 임명·박탈 종류로 기록합니다.

이는 **일반 사용자 계정의 Google 인증 그 자체**를 막거나 해제하지 않습니다. 임명/철회는 **CMS 관리자 권한**에만 적용됩니다.

### 불변 계정 보호

- 창조자 자신은 관리자 임명/박탈 API에서 대상으로 지정할 수 없습니다.
- 선생님도 같은 기본 계정 보호를 받습니다.
- 1순위 선생님, 2순위 임명 관리자 모두 다른 사람의 관리자 권한을 조정할 수 없습니다.
- 창조자 이메일은 `OWNER_EMAIL`, 선생님 이메일은 `TEACHER_EMAIL` Worker 환경변수로 결정합니다. 두 변수는 배포 주체만 변경할 수 있습니다.
- D1 임명 기록은 **Access JWT의 subject 및 이메일을 함께 확인**합니다. 일반 학생이 임의로 본인이나 다른 사람의 student ID를 전송해 관리자로 승격할 수 없습니다.

## 인증 2중 구조

1. Cloudflare Access Google 제공자가 사용자 계정을 인증합니다.
2. Worker가 서명된 JWT issuer, AUD, subject, email을 검증합니다.
3. Worker는 창조자/선생님 고정 주소 또는 D1의 활성 임명 기록으로 역할을 판정합니다.
4. 관리자 화면과 CMS API에는 **그 계정이 직접 생성한 관리자 비밀번호 해시**를 확인해 발급한 12시간 HttpOnly 쿠키가 추가로 필요합니다.
5. 계정 권한이 철회되면 Worker는 매 요청 현재 역할을 재검증하므로 오래된 관리자 쿠키가 있어도 CMS API는 거부됩니다. 철회 시 해당 로그인 세션도 DB에서 삭제합니다.

관리자 비밀번호 원문은 저장하지 않습니다. 기존 선생님 인증·재설정 스키마를 **계정별**로 확장했고, 다른 사람의 비밀번호/로그인 세션과 공유하지 않습니다.

## D1 구조

추가 스키마: `modern/frontend/migrations/0005_creator_roles.sql`.

- `lab_admin_grants`: 가입된 학생 Access subject + 이메일, 부여한 관리자 역할, 임명자, 시각, 철회 시각.
- `lab_admin_audit`: 창조자의 권한 변경 감사기록.
- 창조자·선생님 고정 권한은 보안 설정으로 관리하므로 위 테이블에 행을 억지로 생성하지 않습니다.

권한 API(창조자 + 별도 비밀번호 세션 필요):

- `GET /api/admin/roles`: 가입된 계정·권한/감사기록 조회.
- `POST /api/admin/roles`: `action=grant|revoke`, `accessSubject=<가입된 계정>`. 동일 Origin + JSON + 커스텀 요청 헤더 필수.

## 보안·운영 주의

- Google Access는 이메일 화이트리스트 없이 학생 로그인을 허용해도 관리자 API는 별도 역할과 2차 비밀번호로 보호됩니다.
- 역할 기록과 개인 학습 기록은 비공개 학생 데이터입니다. API는 창조자/관리자 본인 여부와 권한을 확인하고 인증 외 요청을 차단합니다.
- `sea35652@gmail.com`은 실제 CMS에서 로그인할 Google 계정과 동일해야 합니다. 로그인 중 다른 Google 계정을 선택하면 창조자 권한이 보이지 않습니다.
- 창조자 및 선생님이 이메일 비밀번호 복구를 사용하려면 Cloudflare Email Routing 목적지 주소 인증을 마쳐야 합니다. 계정별 관리자 비밀번호를 최초 설정한 뒤에는 **비밀번호 원문을 외부 채팅·GitHub·관리자 목록에 노출하지 마세요.**
- Cloudflare Free 요청/CPU 제한과 실제 Google Access UI·D1 CRUD의 브라우저 검증은 릴리스 후 별도로 확인해야 합니다.
