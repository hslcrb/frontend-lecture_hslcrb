# 학생 마이페이지 · 성적 분석 · 문제 편집기

Frontend Lab 확장 모듈. 2026-11-09. Cloudflare Workers Free + D1 기반이며 별도의 외부 유료 서비스가 필요 없습니다.

## 학생 경험

1. Google Access 로그인 → 별도 이름 등록. 계정마다 무작위 UUID 기반 **불변 고유 식별자** `FL-xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx` 발급.
2. **`/me`**에서 자기 이름·Google 로그인 이메일·고유 ID·누적 응시 횟수·평균·최고 점수·과목별 기록·최근 응시 이력 조회.
3. **`/practice/<slug>`**에서 교사가 게시한 객관식/단답형 문제 풀이 및 서버 채점·해설 확인.
4. 기존 강의/퀴즈 HTML은 **그대로 사용**하며, 공통 퀴즈 엔진 `quiz-unified.js`를 빌드 과정에서 복사본만 확장해 퀴즈 결과를 해당 학생 D1 기록에 저장.
5. 마이페이지와 학습 API는 인증한 사용자 자신의 Access subject를 기준으로 조회합니다. 클라이언트가 제출한 다른 학생 ID로 조회하지 않습니다.

계정 ID는 로그인 이메일 변경이나 같은 이름의 다른 사용자와 구별할 수 있도록 발급하지만, 로그인·관리자 권한을 부여하는 비밀번호나 토큰은 아닙니다. 계정 ID를 안다고 다른 학생 기록에 접근할 수 없습니다.

교사 계정 `spacejh72@gmail.com`의 **Google 인증 + 기존 D1 비밀번호 세션**이 모두 유효한 경우 `/admin`에 접근합니다. 상단 탭:

| 메뉴 | 기능 |

| 학습 현황 | 등록·활동 학생, 총 응시, 평균 점수 KPI, 최근 14일 평균 점수 추이 SVG, 문제별 점수 그래프, 학생별 평균·최고 점수 목록, 이름/이메일/고유 ID 검색, 개별 학습 이력 |
| 문제 관리 | 객관식·단답형 문제 추가/삭제/이동, 보기 2~6개 편집, 정답/설명 입력, 초안 저장·게시/비공개, 버전 이력, 버전을 초안으로 복원, 기존 퀴즈 가져오기 |
| 강의 파일 CMS | 기존 기능 유지: HTML/CSS/JavaScript 코드 수정·초안·게시·숨김·복원 |

차트는 원본 디자인 시스템의 Pretendard/잉크색/블루/얇은 선을 사용하는 **자체 SVG**로 만들었고, 장식·이모지·화려한 효과는 넣지 않았습니다. 모바일에서도 표가 가로 스크롤되고 대시보드가 1열로 바뀝니다.

## 문제 편집 정책

- 새 관리형 퀴즈는 영문 소문자 slug 3~60자, 제목 1~120자, 문제 1~50개를 받습니다.
- 객관식은 2~6개의 보기와 하나의 정답 인덱스, 단답형은 문자열 정답을 지정합니다.
- 설명·분류는 선택적, 입력 길이 제한 및 정답 유효성 검사는 **서버에서도 재검사**합니다.
- **초안 저장**은 학생들에게 영향이 없고 **게시** 후에야 학생 마이페이지에 등장합니다.
- 편집 중 이전 게시본이 유지됩니다. 이전 버전 불러오기는 초안을 수정하며, 실제 게시하려면 별도로 다시 게시해야 합니다.
- 원본 퀴즈 가져오기는 강의 HTML/JS를 변경하지 않고 별도 관리형 퀴즈로 복사합니다. 원본 경로를 변경하거나 기존 퀴즈를 자동으로 교체하지 않습니다.
- 기존 퀴즈의 JavaScript 자체도 종전 파일 CMS에서 수정할 수 있지만, 정답/보기 구조를 변경하면 **빌드 시 생성한 이전 채점 기준이 무효화**되므로 이전 형식의 점수 저장을 거부합니다. 채점 기록이 필요한 수정은 새 관리형 퀴즈에서 하는 것이 안전합니다.

## D1 데이터 모델

`migrations/0003_learning_profiles_quizzes.sql` (기존 테이블 수정·삭제 없이 추가):

| 테이블 | 의미 |
| --- | --- |
| `lab_student_profiles` | 기존 `lab_students.access_subject`를 기준으로 부여한 불변 `student_id` |
| `lab_quiz_sets` | 새 퀴즈 slug, 제목, 설명, 초안 JSON, 게시본 JSON 및 버전 |
| `lab_quiz_versions` | 게시된 버전의 문제·정답·제목 스냅샷, 복원용 |
| `lab_quiz_attempts` | 학생 ID, 문제 ID/종류, 문제 버전, 정답 수/총 수, 점수, 제출 시각 |

답안 원문은 성적 통계 DB에 저장하지 않습니다. 학생의 타인 정보 조회와 일반 사용자의 정답 키 조회를 막기 위해 Worker가 JWT와 추가 이름 등록을 확인하고, 관리자 API에는 비밀번호 세션을 요구합니다.

### 서버 채점과 부정행위 방지 한계

- 관리형 퀴즈의 정답은 서버의 D1 게시본 JSON에 있으며, **학생 문제 조회 API에는 정답과 해설을 보내지 않습니다**. 제출 시 서버에서 직접 채점합니다.
- 기존 퀴즈는 원래 브라우저 JavaScript 파일에 정답이 포함된 교육 자료입니다. 서버는 빌드 단계에 추출한 원본 정답표와 제출 답안을 비교하지만, 학생이 브라우저에 제공된 기존 자료에서 정답을 볼 수는 있습니다.
- 점수와 응시 기록은 **형성평가·연습용**이며 공식 시험/성적표/보안 시험으로 사용하지 않습니다. 제출 남용 방지를 위해 계정당 24시간 40회 기록 제한이 있습니다.
- 원본 AI/HTML/CSS 등에서 **공통 `quiz-unified.js`를 사용하는 퀴즈에 자동 점수 기록**을 연결했습니다. 다른 자체 채점 엔진이 존재할 경우 별도 어댑터가 필요합니다.

## API 개요

인증된 학생 (Google + 별도 이름 등록 필수):

- `GET /api/session`: 로그인 상태, studentId
- `GET /api/me`: 본인 학습 정보만
- `GET /api/quiz/catalog`: 공개 관리형 퀴즈 + 지원되는 기존 퀴즈 목록
- `GET /api/quiz/managed/<slug>`: 정답/해설을 제외한 공개 문제와 버전
- `POST /api/quiz/managed/<slug>/submit`: 문제 버전과 답안 배열을 제출, 서버 채점·기록
- `POST /api/quiz/legacy/submit`: 기존 화면에서 자동 기록 시 호출, 원본 정답표로 서버 재채점

교사 전용 (Google + 교사 비밀번호 인증 필수):

- `GET /api/admin/learning`: 학생 목록, 통계 및 차트용 집계
- `GET /api/admin/learning/student?studentId=<ID>`: 한 학생의 상세 점수 기록
- `GET /api/admin/quizzes`: 관리형 퀴즈 목록·공개 상태
- `GET /api/admin/quiz?slug=<slug>`: 초안·게시 버전 및 이력
- `GET /api/admin/quiz/legacy` / `GET /api/admin/quiz/import?path=<path>`: 기존 퀴즈 가져오기
- `POST /api/admin/quiz`: save, publish, unpublish, restore

모든 POST는 동일 Origin, JSON Content-Type, 사용자 지정 헤더를 확인합니다.

## 운영 시 주의

새 학생 데이터·점수는 개인 정보와 학습 기록입니다. 교사와 서비스 운영자는 수집 목적·보유기간·열람/정정/삭제 방침을 확정한 뒤 실제 학생에게 배포해야 합니다. 비공개 학생 데이터는 README, 로깅, 저장소 커밋에 포함하지 마세요. 고유 ID의 전체 값도 공개 로그·URL에 불필요하게 남기지 않습니다.
